AuraClock Watch Face Format (WFF) Support Reference
======================================================

AuraClock runs imported Watch Face Format packages strictly offline on-device.
Nothing talks to Google services, no watch pairing is required, and no code
from imported APKs is ever executed.

1. IMPORT FORMATS, STRINGS & DUPLICATE DETECTION
------------------------------------------------
- .apk or .zip containing plain-text res/raw/watchface.xml (or watchface.xml)
- Folder-free watchface.xml (plain-text XML; images/fonts are marked missing)
- Binary compiled XML (AXML) is detected and rejected with an explanation
- Duplicate import detection computes a SHA-256 content hash of watchface.xml +
  resources; re-importing an identical watch face prompts to Replace or Cancel.
- Image & Custom Font (.ttf, .otf, .ttc) resolution order:
  1. Matching filenames under res/drawable*, res/mipmap*, res/font*, assets/, or root
  2. Fallback via built-in resources.arsc reader for R8-shrunk resource paths
     (e.g. res/ab.webp or res/aa.ttf)
  3. Unresolved resources are skipped safely and logged in the compatibility report
- String Resources & Localization:
  - Reads res/values*/strings.xml and resources.arsc string pools using the device's
    active language/region with fallback to default values/.
  - Resolves string resource names in displayName attributes, Metadata, literal
    PartText, and unquoted/expression identifiers (e.g. greeting or @string/greeting).
  - Accepts <Localization calendar="..." locales="..." /> without penalizing score.

2. SUPPORTED ELEMENTS & ATTRIBUTES
----------------------------------
- WatchFace
  - width, height, clipShape (CIRCLE, RECTANGLE, NONE), cornerRadiusX, cornerRadiusY
- Metadata
  - key, value (reads "title" / "name" for face display name)
- UserConfigurations
  - ColorConfiguration (with ColorOption swatches)
  - ListConfiguration (with ListOption entries)
  - BooleanConfiguration
  - PhotosConfiguration (SINGLE or MULTIPLE photo album via zero-permission Android Photo Picker)
  - Flavors / Flavor (one-tap preset bundles setting configurations & default complications)
  - Live editing via the Customize settings bottom sheet, saved per face in SharedPreferences
- ComplicationSlot
  - slotId, displayName, supportedTypes, isCustomizable
  - BoundingOval, BoundingRoundBox, BoundingBox, BoundingArc clipping
  - DefaultProviderPolicy mapping to offline AuraClock data providers:
    Steps, Battery, Next Event, Timer, Stopwatch, Date, Day of Week, or Off (Empty)
  - Complication templates (SHORT_TEXT, LONG_TEXT, RANGED_VALUE, GOAL_PROGRESS,
    MONOCHROMATIC_IMAGE, SMALL_IMAGE, WEIGHTED_ELEMENTS, EMPTY) + fallback rendering
  - Tapping a slot on the watch face opens its related AuraClock tab
- BitmapFonts
  - BitmapFont (name) containing Character and Word glyph image entries
- Scene & Group
  - backgroundColor (hex or expression), Group children (with saveLayer compositing for masks)
  - Condition / Expressions / Compare / Default, Variant, Transform, Animation
- AnalogClock & DigitalClock
  - HourHand, MinuteHand, SecondHand (Sweep & Tick motion policies)
  - TimeText (format/timeFormat, hourFormat: 12 / 24 / SYNC_TO_DEVICE, Shadow, Outline, BitmapFont)
- PartImage & Photos
  - Image, Images, Photos (change="TAP" / "ON_VISIBLE", changeAfterEvery, defaultImageResource)
  - blendMode: SRC_OVER, MULTIPLY, SCREEN, ADD, OVERLAY, DARKEN, LIGHTEN,
    SRC_IN, SRC_ATOP, DST_IN, DST_OUT, DST_OVER, XOR
- PartText & PartDraw
  - Template + Parameter, custom TTF/OTF, BitmapFont, Shadow, Outline
  - Ellipse, Rectangle, RoundRectangle, Arc (with Transforms), Line

3. SUPPORTED DATA SOURCES & PROVENANCE
--------------------------------------
Time & Date (AuraClock data):
- HOUR_0_11, HOUR_0_11_Z, HOUR_1_12, HOUR_1_12_Z, HOUR_0_23, HOUR_0_23_Z, HOUR_1_24, HOUR_1_24_Z, HOUR
- HOUR_0_11_TENS_DIGIT, HOUR_0_11_UNITS_DIGIT, HOUR_0_23_TENS_DIGIT, HOUR_0_23_UNITS_DIGIT
- HOUR_0_11_MINUTE, HOUR_0_23_MINUTE, MINUTE*, SECOND*, MILLISECOND, SECOND_MILLISECOND
- AMPM_STATE, AMPM_POSITION, AMPM_STRING, IS_24_HOUR_MODE
- DAY*, DAYS_IN_MONTH, MONTH*, YEAR*, DAY_OF_WEEK*, FIRST_DAY_OF_WEEK
- SECONDS_IN_DAY, UTC_TIMESTAMP, TIMEZONE*

Phone Sensors (Real phone sensor — active ONLY while visible on screen):
- STEP_COUNT, STEP_GOAL, STEP_PERCENT (requests ACTIVITY_RECOGNITION only if needed)
- HEART_RATE, HEART_RATE_Z, HEART_RATE_IS_AVAILABLE
- LIGHT_LEVEL, ILLUMINANCE
- AMBIENT_PRESSURE, PRESSURE, PRESSURE_HPA
- ACCELEROMETER_IS_SUPPORTED, ACCELEROMETER_X/Y/Z, ACCELEROMETER_ANGLE_X/Y/Z/XY

Complications & User Settings (AuraClock data):
- COMPLICATION.TEXT, COMPLICATION.TITLE, COMPLICATION.RANGED_VALUE*, COMPLICATION.GOAL_PROGRESS*,
  COMPLICATION.WEIGHTED_PERCENT_CONFIG, COMPLICATION.MONOCHROMATIC_IMAGE, COMPLICATION.SMALL_IMAGE
- CONFIGURATION.<id> and CONFIGURATION.<id>.<swatchIndex>

Offline Unreachable Data (No data):
- WEATHER.* (WEATHER.IS_AVAILABLE evaluates false offline; WEATHER.CONDITION_NAME evaluates "--")
- UNREAD_NOTIFICATION_COUNT (0 offline without NotificationListener access)

4. EXPRESSIONS & PERFORMANCE
----------------------------
- Full WFF operator set, conditional/ICU, math/trig, string formatting, conversion & color functions.
- Compiled ASTs are LRU-cached (512 entries) and re-evaluated only when dependency inputs change.
- Animations and SensorManager listeners register strictly while visible (RESUMED) and unregister
  immediately when leaving the clock screen or turning the screen off.

5. COMPATIBILITY & DIAGNOSTICS
------------------------------
- Each imported face reports a 0..100% compatibility score plus per-source provenance
  ("Real phone sensor", "AuraClock data", or "No data") in Face details and Diagnostics.
- Diagnostics -> Phone Sensors shows live hardware & permission status and active listener count.
